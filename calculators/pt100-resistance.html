RTD & Temperature Sensor Resistance Calculator

Calculate the expected resistance of common industrial and HVAC temperature sensors from their temperature. Select the sensor type to use the appropriate resistance-temperature characteristic.

Why Sensor Type Matters

Temperature sensors do not all follow the same resistance curve. Selecting the correct sensor characteristic is therefore just as important as entering the correct temperature.

Platinum RTDs

PT100 and PT1000 sensors use the standardized IEC 60751 platinum characteristic. Their curves have the same shape; the primary difference here is the nominal resistance at 0 °C:

  • PT100 → 100 Ω at 0 °C
  • PT1000 → 1000 Ω at 0 °C

The same IEC 60751 coefficients are used for both. :contentReference[oaicite:2]{index=2}

Ni1000

A Ni1000 is a nickel RTD with a nominal resistance of 1000 Ω at 0 °C. Nickel sensors have a substantially different resistance curve from platinum RTDs.

The calculator uses the DIN 43760 nickel characteristic for the selected Ni1000 sensor. DIN 43760 nickel sensors are commonly identified by their relatively high temperature coefficient compared with platinum RTDs. :contentReference[oaicite:3]{index=3}

10k Type II

A 10k Type II sensor is an NTC thermistor, not a platinum or nickel RTD.

Its resistance decreases as temperature increases. For this calculator, the assumed characteristic is:

  • 10,000 Ω at 25 °C
  • B = 3975 K

Those parameters correspond to the Type II characteristic documented by Honeywell for its 10k Type II sensor family. Always verify the manufacturer's curve when working with an unidentified 10k sensor. :contentReference[oaicite:4]{index=4}

PT100 and PT1000

Standard IEC 60751 platinum RTDs use the Callendar–Van Dusen equation. For temperatures at or above 0 °C:

R(t) = R0 × [1 + A×t + B×t²]

Where:

  • R(t) = resistance at temperature t
  • R0 = resistance at 0 °C
  • A = 3.9083 × 10⁻³
  • B = −5.775 × 10⁻⁷

For temperatures below 0 °C, the IEC 60751 equation includes an additional cubic correction term. :contentReference[oaicite:5]{index=5}

R0 = 100 Ω

PT1000 at 100 °C

The PT1000 is essentially the same normalized platinum curve multiplied by ten. :contentReference[oaicite:6]{index=6}

Ni1000

The Ni1000 calculation uses a polynomial characteristic associated with the DIN 43760 nickel sensor family.

R(T) = R0 × [1 + A×T + B×T² + C×T⁴ + D×T⁶]

For the characteristic implemented here:

R0 = 1000 Ω
A = 5.485 × 10⁻³
B = 6.650 × 10⁻⁶
C = 2.805 × 10⁻¹¹
D = −2.000 × 10⁻¹⁷

These coefficients produce a substantially steeper resistance change than a PT100 over typical HVAC/control temperatures. :contentReference[oaicite:7]{index=7}

10k Type II Thermistor

The 10k Type II calculation uses the Beta model:

R = R25 × exp[B × (1/T − 1/T25)]

Temperatures in this equation are absolute temperatures in Kelvin.

  • R25 = 10,000 Ω
  • B = 3975 K
  • T25 = 298.15 K
  • T = measured temperature in Kelvin

Because this is an NTC thermistor, the resistance falls as temperature rises. Honeywell's published Type II table, for example, lists approximately 32.19 kΩ at 0 °C, 12.46 kΩ at 20 °C, and 5.83 kΩ at 37.8 °C. :contentReference[oaicite:8]{index=8}

Field Troubleshooting

This is where knowing the sensor characteristic becomes particularly useful.

Step 1 — Identify the sensor

Before interpreting a resistance measurement, determine what sensor you actually have. Look at:

  • Sensor label
  • Part number
  • Transmitter configuration
  • Controller input configuration
  • Manufacturer documentation
  • Wiring drawings

Step 2 — Estimate the actual temperature

Use the surrounding conditions to establish a reasonable expectation. A room sensor sitting in a normal occupied space should not suddenly measure a resistance corresponding to several hundred degrees.

Step 3 — Measure resistance

Compare the measured resistance with the expected resistance for the identified sensor.

Step 4 — Check the wiring

Remember that the resistance measured at the controller may include wire resistance, terminal resistance, and connection problems.

Important Difference: RTD vs. Thermistor

Don't assume every resistance temperature sensor is an RTD.

A PT100, PT1000, and Ni1000 are RTD technologies. A 10k Type II is typically an NTC thermistor. Their curves are fundamentally different.

If you select the wrong sensor type, you can get a mathematically precise answer that is completely wrong for the actual sensor.

Common Mistakes

  • Assuming every 1k sensor is a PT1000: A Ni1000 and PT1000 both have a nominal 1000 Ω reference value but have different resistance-temperature curves.
  • Assuming every 10k sensor is identical: Manufacturer-specific thermistor curves can differ.
  • Confusing RTDs and thermistors: They are different sensor technologies.
  • Ignoring lead resistance: Particularly important with lower-resistance sensors and long runs.
  • Using a nominal value as an exact value: Real sensors have manufacturing tolerances.
  • Skipping the controller configuration: The sensor and receiving device must use compatible characteristics.
