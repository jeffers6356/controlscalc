PLC Raw Count Scaling Formula

A PLC analog input often represents a field signal as a numerical raw value. The PLC program then converts that raw value into engineering units such as PSI, temperature, percentage, flow, or level.

Engineering Value = Engineering Low + ((Raw Input − Raw Low) ÷ (Raw High − Raw Low)) × (Engineering High − Engineering Low)

The raw-count range depends on the controller, analog input module, resolution, configuration, and data format. Always verify the actual values used by the PLC system.

Example

Suppose a PLC analog input uses a raw range of 3277 to 16384 counts to represent 0–100 PSI.

If the PLC reads 9830 counts:

0 + ((9830 − 3277) ÷ (16384 − 3277)) × 100 = 50.0 PSI

The calculated engineering value is approximately 50 PSI.

Troubleshooting PLC Scaling

The field signal is correct but the PLC value is wrong

Measure the actual transmitter signal first. If the measured 4–20 mA or 0–10 V signal is correct but the displayed engineering value is wrong, check the analog input configuration, raw-count range, scaling formula, engineering limits, and PLC logic.

The raw count is correct but the engineering value is wrong

Verify that the PLC program is using the correct raw minimum, raw maximum, engineering minimum, and engineering maximum. Also check for offsets, clamping, filtering, or additional signal processing.

The raw value is outside the expected range

An out-of-range raw value can indicate an over-range or under-range field signal, incorrect input configuration, wiring problems, or a raw-count range that does not match the actual analog input module.

Common Mistakes

  • Using the wrong raw-count minimum or maximum.
  • Assuming every PLC uses the same raw-count range.
  • Scaling a 4–20 mA input as though it were 0–20 mA.
  • Reversing the engineering-unit minimum and maximum.
  • Ignoring negative engineering ranges.
  • Troubleshooting the PLC value without first measuring the actual field signal.
  • Forgetting that PLC logic may apply additional scaling, offsets, filtering, clamping, or square-root extraction.

Engineering Note

This calculator performs a general linear conversion between a raw input range and an engineering-unit range. PLC raw-count values are not universal. Different controllers and analog input modules can use different numerical ranges depending on hardware, resolution, configuration, and data representation.

For field troubleshooting, verify the actual analog signal, I/O configuration, raw value, and PLC scaling logic rather than assuming a particular manufacturer's raw-count range.
