4–20 mA Reference Table

For a standard linear 4–20 mA signal, these values represent the percentage of configured transmitter span.

Current Span Across 250 Ω
4 mA 0% 1 V
8 mA 25% 2 V
12 mA 50% 3 V
16 mA 75% 4 V
20 mA 100% 5 V
Engineering Value = LRV + ((mA − 4) ÷ 16) × (URV − LRV)

Always use the transmitter's configured LRV and URV. Do not assume that 4 mA always represents zero engineering units.

PLC Scaling Reference

The general linear scaling relationship can be used when converting an input value into an engineering range.

Output = Output Low + ((Input − Input Low) ÷ (Input High − Input Low)) × (Output High − Output Low)

PLC raw-count ranges vary by controller, analog input module, configuration, resolution, and data format. Verify the actual module documentation before using a specific raw-count range.

Field Troubleshooting Checklists

4–20 mA Signal

  1. Verify the transmitter configuration and its LRV/URV.
  2. Measure the actual loop current with the correct meter method.
  3. Check loop power supply voltage and available voltage budget.
  4. Check wiring, terminals, polarity, and added resistance.
  5. Verify the analog input is configured for the expected signal type.
  6. Check PLC raw counts and scaling.
  7. Compare the PLC value with the transmitter's measured process value.

0–10 V Signal

  1. Verify the expected signal range and common/reference connection.
  2. Measure the voltage directly at the source.
  3. Measure again at the receiving input when practical.
  4. Check wiring, polarity, grounding, and voltage drop.
  5. Verify the analog input configuration.
  6. Check PLC scaling and the displayed engineering value.
