What Is an RTD?

RTD stands for Resistance Temperature Detector. An RTD measures temperature by using the predictable change in electrical resistance that occurs as the sensing element's temperature changes.

RTDs are commonly used in industrial automation, process control, HVAC systems, laboratory equipment, and other applications where accurate temperature measurement is required.

Common RTD types include PT100 and PT1000 sensors.

Key concept: An RTD is fundamentally a resistance device. When troubleshooting one, measuring resistance is often the most useful first diagnostic step.

What Is a PT100?

A PT100 is a platinum RTD with a nominal resistance of 100 Ω at 0 °C.

Its resistance increases as temperature increases.

PT100 at 0 °C ≈ 100 Ω

The actual resistance at a particular temperature is determined by the applicable RTD characteristic and standard, such as IEC 60751.

This means a PT100 should not be treated as a simple resistor with a fixed temperature coefficient when high accuracy is required.

RTD Resistance

A PT100 has approximately the following resistance values near common operating temperatures:

Temperature Approximate PT100 Resistance
0 °C 100.00 Ω
25 °C 109.73 Ω
50 °C 119.40 Ω
100 °C 138.51 Ω

These values are useful as field reference points. For precise temperature calculations, use the applicable RTD standard and sensor specification.

2-Wire, 3-Wire & 4-Wire RTDs

2-Wire RTD

A 2-wire RTD has two conductors connected directly to the sensing element.

The resistance of the connecting wires is therefore included in the measured resistance.

This can introduce significant measurement error when long cable runs or high accuracy are involved.

3-Wire RTD

Three-wire RTDs are common in industrial control systems. The third wire allows the measuring device to compensate for much of the resistance of the connecting leads.

For the compensation to work correctly, the appropriate wires generally need to have similar resistance.

4-Wire RTD

Four-wire RTDs provide a higher-accuracy measurement by separating the excitation and measurement paths.

This configuration can largely eliminate the effect of lead resistance when used with an appropriate measurement circuit.

Important: Always verify the transmitter or controller's RTD input wiring requirements. Wire colors and terminal arrangements are not universal.

How to Measure an RTD

A digital multimeter can be used to make a basic resistance check of an RTD.

  1. Disconnect the RTD from the measuring circuit when appropriate.
  2. Set the meter to resistance (Ω).
  3. Identify the sensor conductors.
  4. Measure the resistance across the appropriate conductors.
  5. Compare the measured resistance with the expected value.

For a 3-wire RTD, measure the resistance between the conductors according to the sensor's wiring arrangement. Two of the combinations should typically include the sensing element, while the relationship between the readings can help identify the common lead.

Field tip: Record the actual sensor temperature at the time of the resistance measurement. A resistance value by itself is much more useful when you know what temperature the sensor is physically experiencing.

Estimating Temperature from Resistance

Once the RTD resistance has been measured, it can be compared with the expected resistance-temperature relationship.

Example:

A PT100 measures approximately 119.4 Ω.

That is consistent with a temperature of approximately 50 °C for a standard PT100 characteristic.

For temperatures above 0 °C, a commonly used approximation is:

R(T) = R₀ × [1 + A·T + B·T²]

where the coefficients and applicable temperature range depend on the RTD standard.

For precision work, use the complete standard equation or the manufacturer's calibration data rather than relying on a simplified approximation.

Common RTD Faults

Open Circuit

A broken conductor or failed sensing element can produce an open circuit.

Depending on the controller, transmitter, or PLC input, an open RTD may appear as a very high temperature, a fault condition, or another configured failure indication.

Short Circuit

A shorted sensor or conductors can produce an unusually low resistance and therefore an abnormally low indicated temperature or sensor fault.

Incorrect Resistance

A sensor can develop resistance that does not correspond to its actual temperature because of damage, contamination, incorrect sensor type, or wiring problems.

Intermittent Connection

Loose terminals, damaged conductors, vibration, or moisture can cause an RTD signal to change intermittently.

Lead Resistance

One of the most common sources of RTD measurement error is the resistance of the connecting wires.

With a 2-wire RTD, the resistance of both conductors is added directly to the sensor resistance seen by the measuring instrument.

Suppose a PT100 has an actual resistance of 109.73 Ω, but the two connecting conductors contribute 2 Ω total.

The measuring device may see approximately:
109.73 Ω + 2 Ω = 111.73 Ω
That additional resistance can produce a noticeable temperature error.

Three-wire and four-wire configurations are commonly used to reduce the effect of lead resistance.

Checking the Controller Input

If the sensor resistance appears correct but the controller indicates the wrong temperature, investigate the input configuration.

Check:

  • RTD type
  • PT100 vs PT1000 selection
  • 2-wire, 3-wire, or 4-wire configuration
  • Temperature units
  • Input range
  • Sensor fault settings
  • Input filtering
  • Scaling or offset
PT100 vs PT1000 matters. A PT100 and PT1000 do not have the same nominal resistance. Selecting the wrong sensor type in a controller can result in a large temperature error even when the sensor and wiring are functioning correctly.

Field Troubleshooting Workflow

  1. Verify the actual process temperature. Use a suitable independent measurement when possible.
  2. Identify the sensor type. Confirm PT100, PT1000, or another RTD type.
  3. Identify the wiring configuration. Determine whether the sensor is 2-wire, 3-wire, or 4-wire.
  4. Inspect the wiring. Check terminals, connectors, cable damage, and signs of moisture or corrosion.
  5. Measure resistance. Compare the measured resistance with the expected value for the actual sensor temperature.
  6. Check lead resistance. Particularly for 2-wire installations or long cable runs.
  7. Check controller configuration. Verify sensor type, wiring configuration, scaling, units, and input settings.
  8. Check the controller input. If the sensor and wiring are correct, investigate the input hardware or signal conditioning.
Good troubleshooting practice: Separate the problem into three sections: sensor → wiring → controller. Verify each section independently instead of assuming the displayed temperature identifies the failed component.

Common Fault Examples

Example 1: Temperature Reads Extremely High

An open RTD circuit can cause some controllers to interpret the input as an extreme temperature or sensor fault.

Check the sensor and wiring for an open circuit before replacing the controller.

Example 2: Temperature Reads Extremely Low

Check for a shorted sensor or wiring fault. Also verify that the controller is configured for the correct RTD type.

Example 3: Temperature Is Consistently Too High

If the error is consistent, check sensor type, lead resistance, wiring configuration, scaling, and calibration.

Example 4: Temperature Jumps Around

Inspect terminals and wiring for intermittent connections. Vibration, damaged cable, moisture, and loose terminals can cause intermittent RTD readings.

Example 5: PT100 Measures Correctly but Controller Is Wrong

If the measured resistance agrees with the actual temperature, investigate the controller configuration and input hardware.
